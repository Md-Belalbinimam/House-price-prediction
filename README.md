# House Price Prediction 

##  Project Overview

This project focuses on predicting house prices using Machine Learning and Python. It uses the California Housing Dataset and explores different regression algorithms to understand how machine learning models predict housing prices.

## Objectives

- Understand and explore a housing dataset.
- Perform data preprocessing and feature scaling.
- Train regression models.
- Apply cross-validation.
- Perform hyperparameter tuning.
- Compare model predictions.

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

##  Dataset

## California Housing Dataset ## 

The dataset contains housing information from California, including features such as:

- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Average Occupancy
- Latitude
- Longitude

Target: Median House Value

##  Machine Learning Algorithms

- Linear Regression
- Ridge Regression
- Lasso Regression

##  Project Workflow

1. Import libraries.
2. Load the California Housing Dataset.
3. Convert the dataset into a Pandas DataFrame.
4. Separate independent and dependent features.
5. Split the dataset into training and testing sets.
6. Apply Standard Scaling.
7. Train Linear Regression.
8. Perform Cross-Validation.
9. Apply Ridge Regression with GridSearchCV.
10. Apply Lasso Regression.
11. Generate predictions.
12. Analyze prediction errors.
